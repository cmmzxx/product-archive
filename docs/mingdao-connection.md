## 请求与解析规则

- 只调用上述产品列表接口，不查询图纸或附件，不执行写接口。
- 传递 pageIndex、pageSize，默认每页 50 条；接口上限为 1000。
- 传递 tableView=true、useFieldIdAsKey=true，只请求名称和编码字段。
- 请求 includeTotalCount=true；成功响应中的 data.total 用于下一页判断；缺失时保留未知总数。
- 关键词使用名称包含 OR 编码包含，服务端筛选，不在当前页本地冒充全局搜索。
- 按产品编码、rowid 升序；编码未配置时改为名称、rowid 升序。
- 已核验响应为 data.rows 数组，字段以 ID 为键；另兼容官方 v3 文档的 fields 数组结构。
- 成功状态与业务错误码同时检查；缺少记录 ID、名称映射错误、非法 JSON 或结构错误均不能变成成功空列表。
- 单次请求及响应读取共用 30 秒超时；用户取消原样传递；认证、权限、限流和服务错误使用不含敏感原文的提示。
- 当前不自动重试失败请求，用户通过刷新重试；认证请求不自动跟随重定向。

产品列表协议参考 [HAP 官方应用开放接口文档](https://apidoc.mingdao.com/)。当前私有部署的路径、Bearer 认证和 rowid 返回格式以本次实测为准，不要求 AppKey/Sign。

## Windows 本机认证

非秘密配置已写入 Desktop 的 appsettings.json，无需重新填工作表和字段。连接令牌通过 `TOPSOLID_MINGDAO_TOKEN` 传入，变量值只包含令牌，不含 `Bearer ` 前缀。

推荐首次联调：

```powershell
.\scripts\verify.ps1
.\scripts\start.ps1
```

start.ps1 隐藏输入令牌，传给当前程序，结束后恢复调用环境；不落盘、不放进 dotnet 命令参数。令牌来源为这套私有部署为目标使用者授权的连接凭据。不要将令牌贴进源码、需求文档或 Git。

若直接从 Visual Studio 或已发布 EXE 启动，请保证父进程环境中存在该变量。令牌变更或过期后，更新启动环境并重新启动应用；当前不实现自动续期。

Bearer 形式本身不证明权限仅限读取，也不证明等同于设计人员个人身份。正式向其他人分发前，必须确认令牌的实际可见范围与有效期；当前代码只发送查询请求，不会收窄一个宽权限令牌的服务端能力。当前进程环境变量用于联调，正式存储方案另行落实。
